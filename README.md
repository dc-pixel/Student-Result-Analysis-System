# Student Result Analysis System

A responsive student result management and analysis web application.

## Features

- Dashboard with result statistics and performance trends
- Add, edit, delete, and search student results
- Automatic total, percentage, grade, and pass/fail calculation
- Subject-wise performance analysis
- Class/section filtering
- Top performers and at-risk students
- CSV export
- Persistent browser storage
- Responsive UI for desktop and mobile

## Run locally

This project is a zero-build static web app.

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy

It can be deployed directly to Vercel, Netlify, GitHub Pages, or any static hosting provider.
